## Final documentation candidate

setup before comparisons, confirmation and optional CLI workflows. The separate
benchmarking/thread-pinning/process-placement guides are included in the
existing `Suite` and `platform` rustdoc pages, with no new public API.
`cargo package --list` includes all three Markdown sources. Local HTML parsing
verified `writing-benchmarks`, `thread-pinning` and `verified-cpu-placement`.
The generated crates.io README follows the same progression.
